# bfe schedule maker

週間予定表を作り、正方形のPNG画像としてダウンロードできるwebアプリです。

## できること

- 標準の画像ヘッダー、端末から選んだ画像、画像なしを選択
- 日付を選び、その週の月曜〜日曜を自動設定（月・年をまたぐ週にも対応）
- 各曜日の実施／休みと、時間を含む内容（最大80文字）を編集
- 編集結果をプレビューし、1200 × 1200pxのPNG画像をダウンロード
- スマートフォンからも編集・保存

画像と入力内容はブラウザー内で処理し、サーバーには送信しません。保存機能はPNGのダウンロードのみです。再読み込みすると編集内容は初期状態に戻ります。

## 開発・起動

Node.js 22.12以上とpnpm 12.15.0を使用します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

表示されたURLをブラウザーで開いてください。

```sh
pnpm test     # 日付計算・休み表示・長文レイアウトのテスト
pnpm build    # dist/ に静的サイトを生成
pnpm preview  # ビルドしたサイトを確認
```

`dist/` を静的ホスティングに配置できます。相対パスでアセットを参照するため、サブディレクトリへの配置にも対応します。

## 使い方

1. 「週の日付」で予定表にしたい週の日を選びます。入力欄はその週の月曜日になります。
2. ヘッダーを選択します。「画像を選ぶ」ではPNG・JPEG・WebPを使用できます。画像は中央を基準に3:1で切り抜きます。
3. 各曜日の内容を入力します。休みの日は「休み」をオンにすると、予定表に「お休み」と表示します。オフに戻すと入力済みの内容が復元されます。
4. プレビューを確認し、「PNGをダウンロード」を押します。

仕様・設計は [docs/design.md](docs/design.md)、更新履歴は [changelog.md](changelog.md) を参照してください。
