# 週間予定表の仕様・設計

## 目的

`images/sample.png`を参考に、画像ヘッダーと月曜〜日曜の7行からなる正方形の週間予定表をブラウザー内で作る。

## 入力と表示

- 起動時は今日を含む週の月曜日を開始日とする。週の日付を変更すると、その日を含む月曜〜日曜の日付を再計算する。
- 日付計算はローカルの暦日を用い、UTC変換による日付ずれを避ける。月末、年末、うるう年に対応する。
- 各曜日は独立した内容（80文字以内）と休みフラグを持つ。平日は実施、土日は休みを初期状態とする。
- 内容欄に時間と活動名をまとめて入力する。休みの日は内容欄を無効にし、入力値を保持したまま出力だけを「お休み」にする。
- ヘッダーは同梱の`images/image.png`、ローカル画像（PNG/JPEG/WebP）、画像なしから選ぶ。同梱画像は初期状態でも使用する。
- ローカル画像は中央を基準に3:1で切り抜く。読み込みに失敗した場合は直前のヘッダーを維持し、エラーを表示する。
- 画像なしの場合はアプリ名と週の期間を表示する。

## 出力

- Canvasの実サイズは1200 × 1200px。プレビューとダウンロードは同じCanvasを使い、表示と保存結果の差をなくす。
- 上部400pxをヘッダー、下部を曜日・月日・内容の7行とする。平日はターコイズ、土日はピンクで区別する。
- 内容は幅に合わせて折り返し、最大3行に収まるよう文字サイズを調整する。ユーザー入力はHTMLとして解釈しない。
- PNGのファイル名は`bfe-schedule-YYYY-MM-DD.png`（月曜日の日付）。画像の読み込み中はダウンロードを無効にする。
- 入力変更時に即時再描画する。ブラウザーのフォント準備後に出力できる状態とする。

## 構成

- Vite + JavaScript + CSS。実行時ライブラリやサーバーAPIは使わない。
- `src/schedule.js`: 暦日・週計算、初期予定、表示内容の決定。
- `src/render.js`: Canvasの描画とテキストの折り返し。
- `src/main.js`: フォーム、画像の読み込み、ダウンロード処理。
- `src/style.css`: デスクトップの2カラム、モバイルの1カラム表示。
- Node.js標準テストランナーで暦日の境界、休み切り替え、長文の折り返しを検証する。実ブラウザーで入力・画像選択・PNG保存も確認する。

## 動作確認（2026/11/06）

- Node.jsのテスト8件が成功し、Viteの本番ビルドが成功。
- 本番ビルドをChromiumで開き、年越しの日付変更、内容編集、休みのオン／オフと入力値の保持を確認。
- ローカル画像の選択、画像なしへの切り替え、選択画像への復元を確認。壊れた画像ではエラーを表示し、直前の描画を維持。
- ダウンロードしたPNGの署名と1200 × 1200pxの寸法を確認。ファイルとプレビューのPNGデータがバイト単位で一致。
- 幅390pxのモバイル相当表示で横スクロールがないこと、編集・PNG保存ができることを確認。実機のモバイルブラウザーでは未確認。

## 対象外

編集データの永続化、サーバーへの画像送信、ログイン、後方互換・データ移行は行わない。
